Rust 的 2..5，里面藏着一个游标

车传凯 / 2026-05 专题

在纸上写下 2 到 5，把这段区间抄给别人，当然还是同一段。可在 Rust 里，旧的范围类型自己就能当迭代器。比如让 2..5 向前走一步，拿到 2 以后，下一步应该拿 3。这个对象除了描述两端，还记得已经走到了哪儿。如果它随手就能隐式复制一份，哪一份游标往前挪了，很容易看花眼。

Rust 1.96 在标准库里加了一组新的范围类型。现在可以存下一段范围，需要遍历时再把它转换为迭代器。假设编辑器要给一段 ASCII 代码里的拼写错误画线，只想保存起点和终点，等点击时再取那一段。这样的标记可以放进能直接复制的结构里。标记本身不用背着“上一次读到第几个字符”的状态。

我本来以为升级版本，所有写作 2..5 的表达式自然就变了。读到发布说明后半段才发现，1.96 稳定的是新库类型，这个字面量在当时依然产生旧类型。想拿现成代码验证区别，得先看变量的具体类型。只截一行循环，往往看不到这次修改究竟改了哪里。
