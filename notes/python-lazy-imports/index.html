只想看一眼 --help，为什么要等绘图库？

一个命令行工具有三个入口，看帮助、数行数、画图。前两个点进去连一条曲线都不会画，却可能因为文件第一行导入了绘图库，一启动就要等它和它的依赖全部准备好。Python 导入模块时会执行模块顶层的代码，光是看一眼帮助也可能替以后用不到的功能买单。

Python 3.15 加了 lazy import。可以在模块开头写 lazy import matplotlib.pyplot as plt。程序读到这里先记下名字，真正走到 plt.subplots()，需要 plt 这个对象时，才加载模块。写代码的人仍能在文件头看到它依赖什么。只看帮助的人也不用等绘图库，真要出图的人则在第一次用的时候等。

有个细节会影响测试。如果环境里根本没装绘图库，看帮助可能一路正常，直到点「画图」才收到导入错误。一些插件还会在被导入时顺手注册命令，把这类模块改成延迟导入，谁也没有访问它，注册动作就可能一直不发生。所以下次看到有人报开头变快了，我会想同时看看第一次画图的时间，以及缺了依赖时屏幕上给出的错误提示。
