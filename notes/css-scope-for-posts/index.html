给正文里的链接画个边界

一条看起来挺老实的样式，放到博客里就容易出事。比如想给正文链接加下划线，写了 .post a，结果文末作者卡片上的两个小图标也带上了横线。它们也是链接，也恰好住在文章里面。

我喜欢 CSS 的 @scope，因为这个需求可以照着人话翻过去。下面这段从 .post 开始找链接，走到 .author-card 就停。卡片和它里面的链接都在边界外。

以后卡片里多嵌一层头像或社交账号，正文这条规则也不用跟着改。换成给每个正文链接都挂一个专用类，写 Markdown 的人就得记得配合，漏一处的机会大得多。

Firefox 146 在这个月补齐了支持，三个主要浏览器引擎的当期稳定版都能理解这段 CSS。还有一个容易误会的小地方。假如正文外层设置的是文字颜色，卡片里的字仍有可能通过继承拿到这个颜色。边界只管哪些元素会被里面的选择器选中，继承依然按原来的规则走。
