给下拉菜单加个色块，还能保住方向键

假设页面要选主题颜色，一排色块比一排英文色名好认。用普通按钮和列表拼个下拉菜单，鼠标点起来大概很快就像那么回事了。试着把鼠标放下，麻烦才冒出来。按方向键时焦点该去哪？按 Escape 能不能收起来？选了蓝色之后，表单最后到底交了哪个值？

WebKit 写 Safari 27 时演示了另一种办法。保留表单里的 select 和 option，给 select 以及它的 ::picker(select) 设置 appearance: base-select。下拉项里可以摆颜色样本和文字，::checkmark 还可以单独调整选中标记的样式。外观更自由，方向键导航、读屏支持和表单提交这些工作仍由原生控件接手。

我觉得这个例子里的文字值得留着。给三个选项各画一块颜色，看上去很干净，可有些人分不清接近的颜色，读屏软件也需要有意义的名称。写成「海蓝」再配一小块蓝色，装饰没加载时也能选。再往前想一步，旧浏览器里高级样式可能没有效果，简单明确的选项名刚好也能做它的退路。
